# 校园网模块完整目标规格（Shape 草案）

首发 Android 已确认。使用独立的校园网账号页面保存登录信息，之后选择供应商连接，下次自动认证；不建设 App 自有注册服务。本规格不表示已经实现或完成真实登录。

## NETWORK-1：学校认证适配器

默认入口为 https://yc.gxnu.edu.cn/，当前已验证的校园 SSID 为 GXNU-YC。客户端使用学校正常 Dr.COM 流程发现当前页面、终端参数及认证要求，不把其他学校的通用参数当成广西师范大学的实测配置。

供应商按学校真实 pc.js 模板显示：校园网、中国电信、中国联通、中国移动、广电网络；账号后缀依次为空、@ctc、@cuc、@cmc、@gd。选择供应商立即保存到设备，下次使用上一次的选择，不要求再次填写密码。

当前已观察的实际配置为 login_method=1、enable_r3=0、en_md5=0、page_data_encrypt=0，端点是 https://yc.gxnu.edu.cn:802/eportal/portal/login。按用户在真机失败后明确要求的转接方式，客户端加载学校原登录页，等待真实表单和学校提交处理函数就绪，填入已保存的账号、密码和供应商，并只点击一次原登录按钮。实际请求、终端字段、编码和认证配置由学校自己的正常网页流程处理，不以本地解析 loadConfig 成功作为提交账号的前置条件。

客户端只操作学校已核对的可见登录表单 f1，其 DDDDD、upass、ISP_select 和 0MKKey 由学校 ee(1) 处理；不向隐藏的备用 f0 直接提交，不硬编码用户网络地址。需要验证码、用户同意或其他人工操作时停止自动提交，并提供学校原页入口。

早期 default_login 的 /drcom/login、DDDDD/upass/R1/R2/R3/R6/para/0MKKey 是传统备用流程；同一 a40.js 后面的 login.login 赋值覆盖早期分派。客户端点击原按钮，由学校脚本选取实际流程；不声称已验证全部历史模式。

WebView 只运行白名单学校 HTTPS 页面的原脚本，所有网页资源与凭据请求绑定当前目标校园 Wi-Fi，阻断外站及注销。学校网页保存凭据时使用本次页面的内存存储；尝试结束清理并销毁网页，App 自身按用户选择使用设备安全存储。诊断只接收固定状态和错误类别，不执行响应正文作为原生代码，不通过自建云服务转发。result=1、ok 或学校在线页面都不能单独作为外网可用的证明。

## NETWORK-2：真实网络状态

至少区分未连接 Wi-Fi、校园网络待认证、认证中、验证网络、在线、账户错误、学校入口不可达和需要用户操作。无外网时核心首页与设置仍能打开，失败时保留必要输入并给出下一步。

其他 Wi-Fi 或移动数据下不自动提交校园账户。认证和联网检查使用同一目标 Wi-Fi；Android 不以移动数据的联网结果代替校园 Wi-Fi 验证。接口成功但外网验证失败时显示部分完成状态，不显示已可上网。

## NETWORK-3：连接协调

配置完整后，用户从首页一次主操作即可开始正常认证，无需反复进浏览器填写。同一网络的连续点击和重复事件只启动一项任务。

请求有有限超时和重试，不无限提交账户。换网、修改账户或取消时使旧任务失效，迟到结果不能覆盖当前状态。账户错误停止自动重试。学校提示的 120 分钟空闲规则不作为固定强制重登周期。

## NETWORK-4：账户与本地配置

使用独立校园网账号页面显示必要字段，提供固定标签、合适键盘、密码显示切换和字段旁错误说明。保存后首页不反复索取密码，只选择运营商并连接；未经学校认证不把本地保存描述成账号已验证。

保存登录信息是可见的用户选择，凭据使用目标设备安全存储；关闭保存后仅用于当前会话。修改账户使旧凭据与任务失效；删除账户清除密码、账户及相关自动配置。仓库、普通偏好文件及诊断日志不包含明文密码或完整带凭据请求。

账号以学校认证页平时使用的账号为准，不强制只能填学号。保存账号并选中供应商后启用自动连接；关闭保存或自动连接时尊重用户设置，不删改密码中有效的空格或特殊字符。

## NETWORK-5：自动化与快捷入口

自动连接按最终确认的平台能力实施，有可见开关与状态。关闭后不得自动认证；开启后只在目标校园网络、配置完整且无在途任务时触发。

应用打开、系统网络事件、快捷入口和后台监听是不同触发条件。首期明确支持哪些触发、如何启用及哪些条件需要重新打开应用，不将应用运行时检测描述成随时可后台运行。

首期自动认证使用用户主动开启的 Android 常驻服务，显示持续通知并监听校园 Wi-Fi。应用打开时也检查已连接网络。初次开启时按需请求网络识别及通知权限，说明各权限用途；拒绝时提供可理解的提示。系统强制停止、重启或撤销所需权限后，需要重新打开 App 恢复服务，不承诺绕过 Android 后台限制。

## NETWORK-6：故障与诊断

学校页面不可达、证书异常、非预期响应、密码错误或必须人工验证时，提供错误类别以及重试或学校原页入口。日志保留事件、时间与建议，敏感信息脱敏后才可展示或导出。
