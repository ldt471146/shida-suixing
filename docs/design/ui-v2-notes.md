# 师大随行 · 第二版界面

用户希望把每次打开认证网页的动作变成简单的校园连接入口，同时为更多校园服务留下位置。第二版针对「原版界面和字体缺乏设计感」重做布局、字体和小组件，默认使用浅色。没有大块黑色背景。

## 视觉与布局

主色为雾紫蓝 `#6556CF`，页面是奶白 `#F8F8F3`，卡片是白色；淡薰衣草 `#EEEBFC` 用于主网络区域，薄荷 `#E5F3EC` 用于自动连接和服务计划。正文使用墨紫 `#302D46`，辅助文本为 `#6D667F`。深色是可选的蓝灰 `#252B39` / `#313949`，不会使用纯黑页面。

首页按「品牌与学校 → 页面标题 → 网络主卡 → 账号 → 自动连接」排列。网络卡采用白色外壳、浅紫内层和白色操作区；网络名与静态 Wi-Fi 轨道图左右排列，供应商和主按钮直接放在卡内。首页保留真实网络状态、具体建议和当前 Wi-Fi 名称；状态由文字和小点一起表达，不展示虚构网速或流量。

账号页使用明确的字段标签、白色输入卡、密码显示按钮、保存开关、就近校验反馈和删除确认。密码和账号草稿只放在页面内存，不进入 saved instance state。服务页继续从 `CampusModules.available` 构建可用服务并通过 `CampusRoute` 路由；后续服务只以文字计划说明展示。

## 字体与组件

中文使用离线打包的 Noto Sans SC 400 / 600，网络名 `GXNU-YC` 使用 Plus Jakarta Sans 700。所有主题文字禁用合成字重；字体随 APK 提供，离线仍可显示。页面标题为 27 sp，正文为 14–16 sp，辅助信息不小于 12 sp。

圆形 thumb 开关采用 54 × 32 dp 视觉轨道、64 × 48 dp 触控区域和原生 `toggleable` / `Role.Switch` 语义。圆形层次与 180 ms 滑动仅用于实际开关变化；自动连接开关没有日夜图案。主按钮有原生 Button 语义、波纹和 160 ms 按压反馈，忙碌时禁用重复点击并展示真实的 indeterminate progress。动效使用 Compose 动画 API，跟随系统的动画时长缩放；Wi-Fi 轨道图保持静态。

底部三个目的地采用白色浮动导航和浅紫选中区域，支持原生 Tab 选择语义。大字体时导航改为图标上、标签下，主页在窄屏或 fontScale 超过 1.35 时移除装饰插图，为状态与操作保留空间。各页可滚动，账号页处理键盘 insets，页面主体最大宽度为 680 dp。

## 校验记录

静态检查已确认离线字体资源存在，旧系统字体与旧深色页面色值已移除，所有 ConnectionStatus 分支和 CampusActions 保留。当前 Wi-Fi 展示按 `GXNU-YC` 精确匹配，与 core 的 SSID 门禁一致。

根据 sRGB 相对亮度公式计算：白字 / 主色按钮为 5.55:1，正文 / 白卡为 13.21:1，辅助文字 / 浅紫为 4.65:1，辅助文字 / 薄荷为 4.76:1，成功文字 / 薄荷为 5.26:1；深色主按钮为 7.81:1，深色正文 / 卡片为 10.36:1，深色辅助文字 / 主卡为 5.66:1。

编译与真实模拟器的浅色、深色、320 dp、fontScale 1.4、键盘和状态场景验证由主代理统一执行。本记录不把静态检查写成模拟器通过，也不把预览场景写成校园网真实认证成功。
