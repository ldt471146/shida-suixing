# 师大随行 · 排版调整

当前界面采用 Android 系统 SansSerif，中英文、网络名和数字共用一套字体。正文使用常规 400，标题和主要操作使用中等 500；零额外字距，保留系统字号缩放。正文 15–16 sp，辅助信息 13 sp，网络名 17 sp，页头 20–22 sp。不同手机由其本机字体处理字形回退，界面不依赖字体下载。

首页只有品牌与学校页头、网络连接卡和账号/自动连接分组。网络名、状态、供应商与下一步按使用顺序排列；移除重复的大标题、宣传句、轨道插画和多层色块。状态在窄宽度或放大字体时换到下一行。正文使用中性灰，奶白背景和紫色主操作延续现有主题。

内容卡采用 16 dp 圆角、细边框和零阴影。主要按钮为 48 dp 最小高度、12 dp 圆角；开关使用原生 Material Switch。按钮保留波纹反馈、忙碌禁用和进度指示，开关保留可访问名称与状态。底部导航采用普通三项布局，取消浮动外框和巨大胶囊选中块；图标和标签均保留。

账号页保留明确标签、密码显隐、字段校验和保存/删除流程，草稿仍只在页面内存中。服务页显示已接入的校园网与后续计划；我的页采用设置分组。所有 ConnectionStatus 和 CampusActions 保留，认证与存储逻辑未改动。

第二版的打包字体已移至 [字体留档](fonts/README.md)，不再进入 APK。第二版参考记录继续保留在 [ui-v2-notes.md](ui-v2-notes.md)；当前实际效果以模拟器截图和 [检查记录](emulator-verification.md) 为准。
