# 师大随行 · 连接反馈与交互

首页按当前网络状态组织信息：学校与校区页头、连接卡、账号和运营商分组、自动连接设置。连接卡持续显示状态标题、原因和下一步；切换页面或短提示消失后，连接结果仍保留。蓝色表示准备和连接过程，绿色表示已联网，红色表示失败，灰色表示取消或需要切换 Wi-Fi，文字同时说明含义。

浅色以奶白 `#F8F7F2` 为背景、白色为卡片、`#29342F` 为正文、`#68716B` 为辅助文字，主要操作使用蓝色 `#476898`。Android 系统 SansSerif 负责中英文和数字，正文 400、标题和操作 500，零额外字距，保留系统字号缩放。卡片采用细边框、16 dp 圆角和零阴影；主要操作与取消操作保留至少 48 dp 的点击区域。可选深色采用蓝灰背景。

| 文本与背景 | 对比度 |
| --- | ---: |
| 正文 / 白色卡片 | 12.91:1 |
| 辅助文字 / 白色卡片 | 5.04:1 |
| 白色文字 / 主要按钮 | 5.67:1 |
| 主要容器文字 / 浅蓝容器 | 6.12:1 |
| 错误文字 / 错误容器 | 4.87:1 |

连接中保留禁用的主操作文字，另提供取消连接。固定的 Wi-Fi 图形外有单个活动圆环；文字和状态色在 200 ms 内切换。三个阶段为校园 Wi-Fi、账号认证和确认上网，窄屏或大字体时纵向排列。开始前的联网检查属于识别网络，已有互联网连接时可以直接显示联网，不宣称已完成账号认证。等待秒数使用单调时钟，计时协程仅在连接过程中存在。系统关闭动画时保留静态状态图形和全部操作。

账号保存先显示忙碌状态，并等待保存结果；成功后返回，失败时保留输入并在页面内说明原因。空字段校验、密码默认遮罩与显隐、软键盘下的滚动均保留。启动读取设置完成后才决定是否进入首次设置，短提示按反馈事件标识消费，连接原因独立保存在状态中。

参考范围是已查看的 Mobbin [Brilliant](references/mobbin-brilliant.png) 与 [Ultrahuman](references/mobbin-ultrahuman.png) 分组结构，以及 Uiverse 按钮区域的点击反馈。实现使用 Compose 和 Material 控件；参考图片留在设计资料中。

2026-10-06 在 `gxnu_preview` 模拟器上核验，设备为 1080 × 2280、440 dpi。实际点击覆盖连接、取消、取消后重试、连接过程中切换服务页、返回首页后保留联网原因、账号错误进入表单、不可达状态重试、空字段校验、密码显隐、软键盘和滚动、合成预览账号保存。320 dp 宽度及 `font_scale=2.0` 下，取消操作和错误恢复均实际点击成功；两倍字体时滚动后保存按钮完整可见，点击空保存出现字段校验。截图均保留“界面预览 · 未执行校园认证”标记。

原模拟器 `animator_duration_scale` 为未设置的 `null`，该环境最初两帧圆环静止。显式设为 `1` 后，相隔约 250 ms 的两帧圆环区域有 1,890 个像素变化，固定 Wi-Fi 区域变化为 0；显式设为 `0` 后圆环区域变化为 0，取消操作仍成功。检查结束后通过删除临时设置准确恢复原来的 `null`，并恢复显示尺寸、密度、字体和旋转设置。
